LOCAL-FIRST TELEGRAM IMPORTER

Что умеет приложение

Локально читает доступные вашему аккаунту посты и комментарии, сохраняет структурированный JSON и при необходимости скачивает media. Никакой аккаунт автора проекта не используется.

Перейти к парсингу →
01

Какие каналы доступны

Публичные каналы можно передавать ссылкой или через @username. Приватные каналы доступны по ссылке t.me/c/..., только если текущий Telegram-аккаунт уже подписан на них.

02

Если вход прервался

Запросите новый код и попробуйте снова. Временный запрос входа хранится в памяти локального сервера, поэтому после его перезапуска старый код продолжить нельзя.

03

Media по желанию

При парсинге включите «Скачивать media». Фото, видео, голосовые, аудио и документы попадут в папку media рядом с JSON. Экспорт с media скачивается как ZIP.

04

Безопасный повтор

Если Telegram временно недоступен или отдельный пост не обработался, повторите запуск. Записи обновляются идемпотентно, без накопления дублей.

Рекомендации

коротко
  • Для обычного запуска берите 10–50 последних постов.
  • Большое количество media требует больше времени и свободного места.
  • Invite-ссылки не используются: приложение не вступает в каналы самостоятельно.
  • При смене пользователя выполните полный выход в настройках: он отзывает вход в Telegram и удаляет локальные credentials.
  • Не публикуйте `.session`, `.env`, `api_hash`, коды входа и пароль 2FA.
