# Как получить Telegram `api_id` и `api_hash`

Telegram Comments Importer работает через официальный Telegram MTProto API. Для входа нужны **ваши собственные** данные приложения: `api_id` и `api_hash`.

Они создаются бесплатно и используются только локальной копией приложения.

## 1. Откройте сайт Telegram

Перейдите на:

https://my.telegram.org/apps

Убедитесь, что адрес сайта заканчивается именно на `telegram.org`.

## 2. Войдите в свой Telegram-аккаунт

1. Введите номер телефона в международном формате, например `+79991234567`.
2. Telegram пришлёт код в официальное приложение.
3. Введите код на сайте.

Не передавайте этот код другим людям и не сохраняйте его в репозитории.

## 3. Создайте API application

Если приложение ещё не создано, заполните форму:

- **App title** — любое понятное название, например `Telegram Comments Importer`;
- **Short name** — короткое имя латиницей, например `comments_importer`;
- **Platform** — можно выбрать `Desktop`;
- остальные поля можно оставить пустыми, если Telegram их не требует.

Нажмите **Create application**.

## 4. Скопируйте credentials

На странице появятся:

- **App api_id** — числовое значение;
- **App api_hash** — длинная строка символов.

Введите их в окно первичной настройки Telegram Comments Importer.

## 5. Завершите вход

После проверки `api_id` и `api_hash`:

1. Введите свой номер телефона.
2. При наличии Telegram 2FA укажите облачный пароль.
3. Нажмите кнопку отправки кода.
4. Введите код из официального приложения Telegram.

После успешного входа локальная session будет создана автоматически.

## Смена пользователя на одном устройстве

В разделе «Настройки» нажмите «Удалить данные входа». Приложение сначала
отзовёт текущую авторизацию на стороне Telegram, затем удалит локальную
`.session`, `api_id`, `api_hash`, телефон и данные Telegram-профиля. После этого
следующий пользователь начнёт настройку с первого шага и введёт собственные
credentials.

Для полного выхода нужен интернет. Если Telegram не подтвердил logout,
приложение сохранит локальные данные и предложит повторить попытку, чтобы вход
не остался активным в списке устройств.

История парсинга и выгруженные результаты при полном выходе не удаляются.

## Где хранятся данные

При настройке через Web UI:

```text
.local/config.json
.local/sessions/telegram_importer.session
```

Эти пути добавлены в `.gitignore`.

## Важно

- Не публикуйте `api_hash`.
- Не публикуйте `.session` и `.session-journal`.
- Не публикуйте Telegram login code и пароль 2FA.
- `.session` даёт доступ к авторизованному аккаунту и должна защищаться как SSH-ключ.
- Приложение должно запускаться только локально на `127.0.0.1`.
- Никакие операции не проходят через аккаунт автора проекта.
